= Bactrian: plan to v1.0.0
:revdate: 2026-11-15
:toc:

Bactrian is at research stage. It has design documents and a readiness
preflight. It has no proof engine and no OCaml code. This plan is the
execution layer. The work packages WP-00A to WP-09 and the gates G0 to G5 stay
in link:../status/BACTRIAN-ULTRAPLAN.adoc[the detailed plan]. The milestones 0
to 6 stay in link:../architecture/BACTRIAN-IMPLEMENTATION-PLAN.adoc[the
implementation plan]. This file adds the v1.0.0 gates, the models and the
effort.

The work that is shared with the sibling verifiers (`atoma`, `quintessence`,
`Apodeixis.jl`, `canonry`, `chancel`) is in the family plan,
`docs/plan/FAMILY-ULTRAPLAN.adoc` in `hyperpolymath/atoma`. IDs F1 to F12 and
waves W0 to W5 come from that plan.

== Definition of v1.0.0

The detailed plan ends at gate G5 (a COMPLETE receipt). v1.0.0 is G5 for all
three layers, plus the seven family gates. The text below is the Bactrian
reading.

[cols="1,4,3",options="header"]
|===
| Gate | Acceptance | Falsifier
| Language boundary | Closed pure OCaml subset. Effects, `Obj.magic`, exceptions outside the model and unlisted externals fail closed. | An excluded construct passes the subset check.
| Source connection | Obligations come from the typed tree of the compiled unit, bound to the compiler version and the dependency closure. | A body-only mutant keeps the old evidence.
| Semantics | Layer A through Why3. Layer B protocol rules. Layer C ABI obligations. The trusted computing base is published. | A protocol violation or an ABI layout error is accepted.
| Replay | Why3 or SMT results become evidence only through ECHIDNA replay. | UNKNOWN or a timeout becomes COMPLETE.
| Practical coverage | Three pilots, one for each layer. | A second project needs special cases.
| Assurance | Mutation and vacuity checks through ECHIDNA. The preflight and the gate run in CI. | A mutant survives because a gate did not run.
| Release and estate | Deed identity set. README, changelog and claims true. | The repository describes itself as a template.
|===

Bactrian is last in the family order for Layers B and C on purpose. It has no
code to protect, so it gains most from the kit and from the sibling results.
Start B-2 only after `atoma` or `Apodeixis.jl` closes W2 with the kit.

Sonnet does the implementation tasks inside each stage from an Opus brief.
Haiku runs the scout pass before each step. The advisor reviews the close of
each stage and each change to a status word.
