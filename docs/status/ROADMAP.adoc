= bactrian Roadmap

== Current Status

Bootstrap, before any minimum viable product. The repository holds the
architecture, the plans and a fail-closed readiness preflight. It has no Dune
project, no OCaml code and no proof engine. No verification result exists.
All eight authority rows in `.machine_readable/bactrian/authorities.lock` are
`UNPINNED`.

Sources:
link:../architecture/BACTRIAN-IMPLEMENTATION-PLAN.adoc[implementation plan] and
link:BACTRIAN-ULTRAPLAN.adoc[ultra-plan]. The ultra-plan checklist controls
what counts as done.
