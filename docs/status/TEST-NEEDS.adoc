= TEST-NEEDS: bactrian

This file lists the tests that exist in this repository and the tests that
Bactrian still needs. No readiness grade is awarded here.

== Project test

* `tests/bactrian/doctor_test.sh` tests `scripts/bactrian/doctor.sh`.
* It covers the blocked state, bad arguments and duplicate lock rows.
* CI runs it through `.github/workflows/bactrian.yml`.

== Inherited template tests

The estate template supplies the other tests. They check repository shape,
workflows and tooling. They do not test Bactrian logic.

* `tests/workflows/*_test.sh`
* `tests/shape/*_test.sh`
* `tests/e2e/`, `tests/e2e.sh` and `tests/aspect_tests.sh`
* `benches/template_bench.sh` (a benchmark of the template, not of Bactrian)

The Zig test `src/interface/ffi/test/integration_test.zig` is template
scaffold. It contains a placeholder test. It has not been run in this
assessment. Bactrian has no Zig code of its own yet.
